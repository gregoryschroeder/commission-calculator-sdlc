## Steps run

1. `git init` in this directory.
2. Cloned the practice library into a temporary directory outside this repository.
3. `speckit/install.sh <this directory>` — ran `specify init` (Claude integration, sh scripts),
   composed the three template overrides into `.specify/templates/overrides/`, and installed the
   `until-clean` extension (mandatory `after_analyze` hook, `.specify/extensions.yml`).
4. `speckit/install.sh --check <this directory>` — exit 0 (no stale override).

Only files generated by the installer (`.specify/`, `.claude/`) come from that step. None of the
library's own documents are copied into this repository; the constitution cites them by number.

## Observed on install

- The library's kit README says the extension's command lands in
  `.claude/skills/speckit-until-clean-remediate/`. With SpecKit 1.0.9 it was registered as a
  command (`.specify/extensions/.registry`, `registered_skills: []`) and its body lives at
  `.specify/extensions/until-clean/commands/remediate.md`; no `.claude/skills/` entry was created.
  The hook in `.specify/extensions.yml` is still mandatory, so the remediate loop is run from that
  command file after `/speckit-analyze`. *Revisit when:* SpecKit or the kit is upgraded — re-run
  `install.sh`, then `install.sh --check`.

## Re-basing

Re-run `install.sh` after any SpecKit upgrade, then `install.sh --check`; update the table above.
